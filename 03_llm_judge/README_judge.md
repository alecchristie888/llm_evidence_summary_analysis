# LLM-as-Judge Evaluation Pipeline

Evaluates Conservation Evidence summaries generated by four candidate LLMs using
a judge LLM (via OpenRouter) on three metrics:

| Metric | What it measures | Inputs to judge |
|---|---|---|
| **Relevance** | Is this statement relevant to the question? | question + statement |
| **Citation Correctness** | Is the statement supported by its cited action? | statement + cited action document |
| **Faithfulness** | Is the statement supported by *any* of the action docs the summary was built from? | statement + all summary_action_ids docs |

These metrics mirror the human evaluation workflow exactly.

## Setup

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Set your OpenRouter API key

Either create a `.env` file in the project root:
```
OPENROUTER_API_KEY=sk-or-...
```
or export it in your shell:
```bash
export OPENROUTER_API_KEY=sk-or-...
```

### 3. Place your action data files

The judge needs the text content of Conservation Evidence action pages to
evaluate faithfulness and citation correctness. These should be pre-downloaded
local text files in the format used by the student's codebase:

```
action_data/background_key_messages/bg_km_all/
    action_50_clean.txt
    action_52_clean.txt
    ...
```

Update the `action_local_dir` in the CONFIG dict to point to this directory.

**If you don't have local files**, set `action_fetch_from_web: True` in CONFIG —
the loader will fetch pages from `conservationevidence.com` as needed (slower,
requires network, respects a 1-second delay between requests).

## Running the Human Eval Set — All Three Reviewers (Primary)

This is the main entry point. It loads all three reviewer Excel files, filters
to answerable-only questions, and runs the LLM judge over all 820 records.

```bash
cd llm_judge
python evaluate_human_eval_all_reviewers.py
```

### Configuration (edit `evaluate_human_eval_all_reviewers.py`)

```python
CONFIG = {
    # All three reviewer Excel files (relative to working directory or absolute)
    "reviewer_files": [
        "sampled_subset_reviewer1_all.xlsx",
        "sampled_subset_reviewer2_all.xlsx",
        "sampled_subset_reviewer3_all.xlsx",
    ],

    # Filter to answerable questions only (unanswerable crept in by mistake)
    "answerable_only": True,

    # Deduplicate the 57 statements that appear in two reviewer files.
    # True  = evaluate each unique statement once; re-use scores for the
    #         duplicate copy (which keeps its own reviewer metadata).
    # False = evaluate every row independently.
    "dedup_overlaps": True,

    # Path to local action text files
    "action_local_dir": "action_data/background_key_messages/bg_km_all",

    # Where to save results
    "output_file": "llm_judge_results/human_eval_all_reviewers_llm_scores.json",

    # OpenRouter model to use as judge
    "judge_model": "google/gemini-2.5-pro",
    "judge_provider": None,

    # Set to a small number (e.g. 10) for a quick smoke test before the full run
    "max_statements": None,

    "metrics_to_run": ["relevance", "citation_correctness", "faithfulness"],
}
```

```json
  "summary_action_ids": ["2013", "961", "2015", "2016", "2043"],

  "source_file": "sampled_subset_reviewer1_all.xlsx",
  "judge_model": "google/gemini-2.5-pro",
  "judge_provider": null,
  "llm_relevance": {
    "metric_name": "relevance",
    "statement": "Four studies from Mexico...",
    "reasoning": "The statement provides specific factual detail...",
    "verdict": true,
    "raw_verdict": "Yes"
  },
  "llm_citation_correctness": {
    "metric_name": "citation_correctness",
    "statement": "Four studies from Mexico...",
    "cited_action_id": "2013",
    "reasoning": "The cited action document for action 2013 describes...",
    "verdict": true,
    "raw_verdict": "Yes"
  },
  "llm_faithfulness": {
    "metric_name": "faithfulness",
    "statement": "Four studies from Mexico...",
    "reasoning": "The available evidence documents confirm...",
    "verdict": true,
    "raw_verdict": "Yes"
  }
}
```

### Verdict fields
- `verdict: true` = Yes (relevant / correct / faithful)
- `verdict: false` = No
- `verdict: null` = evaluation failed (LLM error or missing data)
- `auto_filled: true` on citation_correctness = no citation present, auto-scored No
- `source_file` = which reviewer Excel file this record came from

## Excel Parsing Notes

### Answerable-only filtering
The human reviewers were asked to evaluate answerable questions only.
Some unanswerable questions crept into the sampled subset by mistake.
`load_human_eval_records(..., answerable_only=True)` (the default) filters
these out automatically based on the `Answerability` column.

### Multi-row format
Each statement group in the Excel may span multiple rows. The first row
carries all metadata; subsequent rows contain only the CE website link column
(one row per cited action URL). The loader collects all CE links and extracts
action IDs from them.

### Whitespace normalisation
Excel stores carriage returns as the literal string `_x000D_` followed by a
newline. Some summaries also have extra blank lines not present in the source
JSON. The loader handles both:
- `_x000D_` sequences are collapsed back to `\n` for display/storage
- For key-matching only (not display), all runs of 2+ newlines are collapsed to
  a single `\n` — this resolves the 33 whitespace-mismatch cases identified
  during development

### Erroneous summaries
A small number of Gemini 2.5 Pro entries in the source JSON have
`relevant_summary` stored as a dict `{"erroneous_summary": "..."}` rather than
a plain string. The index handles this transparently.

## Comparing to Human Scores

After humans complete their evaluations and fill in the Relevance, Citation
Correctness, and Faithfulness columns, you can compute agreement:

```python
import json
import pandas as pd

with open("llm_judge_results/human_eval_all_reviewers_llm_scores.json") as f:
    results = json.load(f)

rows = []
for r in results:
    rows.append({
        "statement": r["statement"][:60],
        "model": r["summary_model"],
        "source_file": r.get("source_file"),
        "human_citation": r.get("human_citation_correctness"),
        "llm_citation": r.get("llm_citation_correctness", {}).get("verdict"),
        "human_relevance": r.get("human_relevance"),
        "llm_relevance": r.get("llm_relevance", {}).get("verdict"),
        "human_faith": r.get("human_faithfulness"),
        "llm_faith": r.get("llm_faithfulness", {}).get("verdict"),
    })

df = pd.DataFrame(rows)

# Agreement rate where human scores exist
for metric in ["citation", "relevance", "faith"]:
    mask = df[f"human_{metric}"].notna() & df[f"llm_{metric}"].notna()
    if mask.sum() > 0:
        agree = (df.loc[mask, f"human_{metric}"] == df.loc[mask, f"llm_{metric}"]).mean()
        print(f"{metric}: {mask.sum()} pairs, {agree:.1%} agreement")
```
