# Data dictionary for data/derived/

Regenerated by `run_all.sh`. Scores are proportions (0–1) unless the column name says otherwise; `_lo`/`_hi` are 95% bootstrap CI bounds (1,000 resamples at the summary level).


## `agent_behaviour_by_model.csv`

Iterations, searches and maximum search offset per completed run, by model.

Columns (11): `model`, `iters`, `iters_lo`, `iters_hi`, `searches`, `searches_lo`, `searches_hi`, `max_offset`, `max_offset_lo`, `max_offset_hi`, `n`


## `agent_errors_by_model.csv`

Tool-error, bad-ID and LLM-error rates (percent of runs), by model.

Columns (10): `model`, `n`, `iters`, `searches`, `docs`, `max_off`, `runs`, `pct_toolerr`, `pct_badid`, `pct_llmerr`


## `attrition_by_model.csv`

Questions never completed and questions hitting the 10-iteration cap on at least one attempt, by model.

Columns (5): `model`, `questions`, `never_completed`, `pct_never_completed`, `hit_cap_at_least_once`


## `claim_failure_rate.csv`

Claim-level failure rates by model.

Columns (4): `model`, `n_claims`, `n_failed_claims`, `claim_fail_rate`


## `claims_long.csv`

One row per judged claim with its failure tags.

Columns (10): `summary_model`, `synopsis`, `question`, `statement_idx`, `claim_idx`, `claim_text`, `support_assessment`, `confidence`, `n_failure_reasons`, `failure_reasons_joined`


## `composite_by_model.csv`

Mean of per-summary recall x faithfulness with CI, under both recall definitions (evaluated_run_paper is the reported one), alongside the model-level product.

Columns (7): `model`, `recall_definition`, `n`, `composite_mean`, `lo`, `hi`, `model_level_product_illustrative`


## `failure_reason_profile.csv`

Mean per-summary rate of each failure reason (per 100 statements) by model with CIs (Fig. 4).

Columns (7): `model`, `failure_reason`, `n_summaries`, `n_tags_total`, `mean_rate`, `lo`, `hi`


## `failure_reasons.csv`

Long format: one row per failure-reason tag on an unfaithful statement.

Columns (9): `summary_model`, `synopsis`, `question`, `statement_idx`, `claim_idx`, `claim_text`, `support_assessment`, `confidence`, `failure_reason`


## `fig1_metric_profile_summary.csv`

Means and 95% intervals plotted in Fig. 1 for the eight Box 1 metrics (percent; bootstrap CIs, Wilson CI for task completion), with n per model x metric.

Columns (7): `class`, `metric`, `model`, `n`, `mean`, `lo`, `hi`

## `fig3_distribution_medians.csv`

Medians and tail fractions (P < 50, P < 70, P >= 90) per model x metric plotted in Fig. 3 (percent scores; retrieval recall evaluated-run).

Columns (7): `metric`, `model`, `n`, `median`, `p_lt_50`, `p_lt_70`, `p_ge_90`

## `retrieval_metrics_by_model_evaluated_run.csv`

Retrieval metrics under the evaluated-run definition (the values reported in the paper): ret_recall, cite_recall, ret_prec, cite_through in percent; n_opened, n_searches, max_offset as counts; each with `_lo`/`_hi` bootstrap 95% CI bounds; n = evaluated summaries.

## `fig4_failure_profile_summary.csv`

Per model x failure reason: mean tags per summary with bootstrap 95% CI (`lo`, `hi`), number and % of summaries with at least one tag (Wilson 95% CI), and the mean per-100-statement rate, as plotted in Fig. 4.

Columns (12): `model`, `failure_reason`, `n_summaries`, `n_tags_total`, `n_affected`, `mean_tags_per_summary`, `lo`, `hi`, `pct_affected`, `pct_affected_lo`, `pct_affected_hi`, `rate_per_100_mean`

## `failure_rate_per_summary.csv`

One row per summary x failure reason: statements scored, tags assigned and rate per 100 statements (the points in Fig. 4).

Columns (7): `model`, `synopsis`, `question`, `n_stmts`, `failure_reason`, `n_tags`, `rate_per_100`

## `fig4_tag_count_shares.csv`

Share of each model's evaluated summaries with 0, 1, 2 or 3+ statements tagged with each failure reason (companion to the Fig. 4 histograms).

Columns (5): `model`, `failure_reason`, `cat`, `n`, `share`

## `inter_rater_disagreements.csv`

Subset of inter_rater_overlap.csv where reviewers disagreed.

Columns (11): `reviewer_1`, `reviewer_2`, `synopsis`, `question`, `summary_model`, `statement`, `metric`, `Reviewer_1_score`, `Reviewer_2_score`, `agree`, `Reviewer_3_score`


## `inter_rater_overlap.csv`

Statements labelled by two or more reviewers with all labels (57 statements, 19 per reviewer pair, x 3 metrics = 171 rows). Regenerated from `data/human_labels/`; identical to the author's copy archived as `data/judge_validation/inter_rater_overlap.csv`.

Columns (11): `reviewer_1`, `reviewer_2`, `synopsis`, `question`, `summary_model`, `statement`, `metric`, `Reviewer_1_score`, `Reviewer_2_score`, `agree`, `Reviewer_3_score`


## `inter_rater_reliability_report.txt`

Console report of inter_rater_reliability.py (pairwise Cohen kappa, Fleiss kappa).


## `judge_validation_table.csv`

Table 1: agreement, kappa, mean absolute bias and bias range per (metric, judge, prompt), with the source comparison file for each row.

Columns (12): `metric`, `judge`, `prompt`, `source_file`, `status`, `n`, `agreement_pct`, `kappa`, `mean_abs_bias_pp`, `bias_min_pp`, `bias_max_pp`, `bias_by_summariser`


## `metric_ranks.csv`

Model means and ranks (1 = best) on every metric, including task completion and the composite.

Columns (19): `model`, `Relevance (mean)`, `Citation rate (mean)`, `CC (all statements) (mean)`, `CC (when cited) (mean)`, `Faithfulness (mean)`, `Retrieval recall (mean)`, `Retrieval precision (mean)`, `Task completion (mean)`, `Composite (recall x faithfulness) (mean)`, `Relevance (rank)`, `Citation rate (rank)`, `CC (all statements) (rank)`, `CC (when cited) (rank)`, `Faithfulness (rank)`, `Retrieval recall (rank)`, `Retrieval precision (rank)`, `Task completion (rank)`, `Composite (recall x faithfulness) (rank)`


## `model_headline.csv`

Model x metric means with bootstrap CIs (Fig. 1).

Columns (6): `model`, `metric`, `n_summaries`, `mean`, `lo`, `hi`


## `outliers_top_bottom.csv`

Best and worst five summaries per model x metric.

Columns (7): `model`, `metric`, `direction`, `synopsis`, `question`, `score`, `n_statements`


## `pairwise_differences.csv`

Differences of summary-level means between models with bootstrap CIs; sig = CI excludes zero.

Columns (7): `metric`, `model_a`, `model_b`, `diff`, `lo`, `hi`, `sig`


## `retrieval_definition_comparison.csv`

Model-level means under the evaluated-run (reported) and log-based definitions side by side.

Columns (33): `model`, `n_summaries`, `recall_log_based_paper`, `recall_log_based_paper_lo`, `recall_log_based_paper_hi`, `recall_evaluated_run`, `recall_evaluated_run_lo`, `recall_evaluated_run_hi`, `precision_log_based_paper`, `precision_log_based_paper_lo`, `precision_log_based_paper_hi`, `precision_evaluated_run`, `precision_evaluated_run_lo`, `precision_evaluated_run_hi`, `opened_log_based_paper`, `opened_log_based_paper_lo`, `opened_log_based_paper_hi`, `opened_evaluated_run`, `opened_evaluated_run_lo`, `opened_evaluated_run_hi`, `cite_through_log_based_paper`, `cite_through_log_based_paper_lo`, `cite_through_log_based_paper_hi`, `cite_through_evaluated_run`, `cite_through_evaluated_run_lo`, `cite_through_evaluated_run_hi`, `searches_evaluated_run`, `searches_evaluated_run_lo`, `searches_evaluated_run_hi`, `max_offset_evaluated_run`, `max_offset_evaluated_run_lo`, `max_offset_evaluated_run_hi`, `n_with_log_based`


## `retrieval_metrics_by_model.csv`

Model-level means and CIs of the log-based retrieval metrics (percent); comparison only, see retrieval_metrics_by_model_evaluated_run.csv for the reported values.

Columns (17): `model`, `ret_recall`, `ret_recall_lo`, `ret_recall_hi`, `cite_recall`, `cite_recall_lo`, `cite_recall_hi`, `ret_prec`, `ret_prec_lo`, `ret_prec_hi`, `conv`, `conv_lo`, `conv_hi`, `n_opened`, `n_opened_lo`, `n_opened_hi`, `n`


## `retrieval_per_summary.csv`

summary_level joined to retrieval metrics under both definitions: `*_run` = trace of the run that produced the summary (from data/summaries; the evaluated-run definition reported in the paper); `*_log` = union over all completed runs in the logs (comparison only).

Columns (25): `summary_model`, `synopsis`, `question`, `n_statements`, `n_cited_statements`, `citation_rate`, `relevance_score`, `cc_all_score`, `cc_cited_score`, `faithfulness_score`, `n_pool`, `n_opened_run`, `n_searches_run`, `max_offset_run`, `n_iterations_run`, `recall_run`, `precision_run`, `cite_through_run`, `n_cited_actions`, `recall_log`, `precision_log`, `n_opened_log`, `cite_through_log`, `cite_recall_log`, `model`


## `retrieval_recall.csv`

Log-based retrieval metrics per (model, question), comparison only: ret_recall, ret_prec, n_opened, cite_recall, n_cited, conv (cite-through).

Columns (8): `model`, `question`, `ret_recall`, `ret_prec`, `n_opened`, `cite_recall`, `n_cited`, `conv`


## `statement_level.csv`

One row per statement (23,641) with judge verdicts and cited action ID.

Columns (12): `synopsis`, `summary_model`, `question`, `statement`, `n_cited`, `rel_verdict`, `cc_verdict`, `cc_auto_no`, `cc_when_cited_verdict`, `faith_verdict`, `n_claims`, `failure_reasons`


## `summary_distribution.csv`

Per model x metric: mean, median, SD, IQR, CV and tail fractions (pct_ge_90, pct_ge_80, pct_lt_70, pct_lt_50).

Columns (12): `model`, `metric`, `n`, `mean`, `median`, `sd`, `iqr`, `cv`, `pct_ge_90`, `pct_ge_80`, `pct_lt_70`, `pct_lt_50`


## `summary_level.csv`

One row per evaluated summary (model x question). Unit of analysis for all headline statistics.

Columns (10): `summary_model`, `synopsis`, `question`, `n_statements`, `n_cited_statements`, `citation_rate`, `relevance_score`, `cc_all_score`, `cc_cited_score`, `faithfulness_score`


## `synopsis_x_model.csv`

Subject area x model means (ED heatmap).

Columns (5): `model`, `synopsis`, `metric`, `mean_score`, `n_summaries`


## `tail_probabilities.csv`

P(score < 50), P(< 70), P(>= 90) per model x metric, including retrieval recall.

Columns (6): `model`, `metric`, `n`, `p_lt_50`, `p_lt_70`, `p_ge_90`


## `tool_traces.json`

Parsed per-run tool traces from the generation logs (all models, including pilots).


## `traces_eval_completed.csv`

One row per completed run in the logs, with in_eval flag for runs whose summary was evaluated.

Columns (16): `query`, `model`, `iters`, `searches`, `details`, `toolfail`, `notfound`, `llmerr`, `complete`, `maxed`, `offsets`, `ks`, `file`, `max_offset`, `in_eval`, `_ord`


## `variance_decomp.csv`

Type II two-way ANOVA sums of squares and eta-squared for model, subject area, interaction and residual.

Columns (4): `metric`, `term`, `ss`, `eta_sq`


## `within_model_correlations.csv`

Pearson r between retrieval-effort variables and faithfulness within each model.

Columns (5): `model`, `x`, `y`, `pearson_r`, `n`


## Other folders

- `data/questions/questions.csv`: question_id, synopsis, question, n_reference_actions, reference_action_ids (semicolon-separated Conservation Evidence action IDs withheld as the reference pool), n_models_with_summary, evaluated.
- `data/summaries/<model>/orig_summaries/*.json`: query, model, provider, relevant_summary, summary_action_ids (cited), tool_call_details (per-iteration tool calls with arguments and return values), all_relevant_action_ids (reference pool), regenerated_ids.
- `data/judge_outputs/by_model/<model>/<area>_llm_scores.json`: one record per statement: synopsis, question, summary, summary_model, summary_action_ids, cited_action_id(s), statement, judge_model, llm_relevance, llm_citation_correctness, llm_citation_correctness_when_cited, llm_faithfulness, failure_reasons and rationales.
- `data/judge_validation/inter_rater_overlap.csv`, `inter_rater_disagreements.csv`: the author's original inter-rater files (28 September 2026), reproduced exactly by `03_llm_judge/inter_rater_reliability.py`.
- `data/judge_validation/llm_vs_human_comparison_*.csv`: 820 rows: source_file, synopsis, question, summary_model, statement, cited_action_id, reviewer, human_* and llm_* labels for relevance, citation_correctness, faithfulness.
- `data/human_labels/*.xlsx`: reviewer spreadsheets as returned (reviewer1 = AT, reviewer2 = VC, reviewer3 = NT; `_all` = original + extras).
- `data/actions/background_key_messages/bg_km_all/action_<id>_clean.txt`: Conservation Evidence action page text (background and key messages), CC BY-NC 4.0. 3,733 actions. Used for question generation, the search index and judging.
- `data/actions/key_messages/km_all/action_<id>_clean.txt`: the same actions as key messages only (no background), CC BY-NC 4.0. 3,742 actions, from an earlier version of the action set. This is the text the `get_action_details` tool returned to the summarisers.
- `data/actions/dense_embeddings_cache/bg_km_nomic_dense_embeddings.npy`: the cached nomic-embed-text-v1.5 embeddings (3,742 x 768) used by the dense half of the hybrid search. They were computed on the earlier 3,742-action set, so use this file rather than regenerating it to reproduce the archived searches.
